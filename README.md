# GetHired

AI-powered job matching platform that connects candidates with recruiters.

## Tech Stack

Frontend
- React (Vite)
- TailwindCSS

Backend
- Node.js
- Express
- MongoDB

## Features

Candidate
- Discover jobs
- Save jobs
- Apply to jobs
- Track applications
- Profile management

Recruiter
- Post jobs
- View applicants
- AI-ranked candidates
